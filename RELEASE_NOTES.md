The first public release of Atmosphere.

- A fast music library and player with folder playlists (including folders you already have), synced lyrics, stats and a mini player.
- Save audio and video you have the rights to keep from SoundCloud, YouTube, Bandcamp, direct file links and 1,000+ other sites, with honest quality choices and full tagging.
- Backups, a clean uninstaller, an opt-in local API for other apps, and automatic signed updates.
